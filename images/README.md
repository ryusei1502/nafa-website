# 写真の置き場所

このフォルダに、下の名前どおりの写真ファイル(.jpg)を置くと、サイトの写真枠に自動で表示されます。
写真がない枠には、青と赤の模様が代わりに表示されます。

- 横長の写真がおすすめです(縦長の枠は `committee.jpg` と `join.jpg` だけ)
- 1枚あたり 500KB 以下にしておくと、表示が速くなります
- ファイル名はすべて半角の小文字です
